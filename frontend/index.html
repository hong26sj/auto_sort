현장 시공사진 업로드

사진 업로드가 완료되면 서버가 백그라운드에서 촬영 위치와 날짜를 확인해 Google Drive에 자동 분류합니다. 업로드 완료 후에는 페이지를 닫아도 됩니다.

📍

촬영 전 위치정보 설정 확인

사진 자동 분류를 위해 촬영 위치(GPS) 정보가 필요합니다.

iPhone 설정 확인
  1. 설정 앱을 엽니다.
  2. 개인정보 보호 및 보안 → 위치 서비스로 이동합니다.
  3. 카메라를 선택합니다.
  4. 앱을 사용하는 동안 허용으로 설정합니다.
  5. 정확한 위치를 켜는 것을 권장합니다.
Galaxy 설정 확인
  1. 카메라 앱을 실행합니다.
  2. 촬영 화면 왼쪽 위의 톱니바퀴(⚙️) 설정 아이콘을 누릅니다.
  3. 톱니바퀴가 바로 보이지 않는 기종은 촬영 화면의 네 점(●●●●) 빠른 설정 아이콘을 누른 뒤 톱니바퀴(⚙️)를 선택합니다.
  4. 카메라 설정 화면을 아래로 내려 위치 태그를 찾아 ON으로 설정합니다.
  5. 휴대폰의 설정 → 위치도 사용 중인지 확인합니다.

※ 위치정보가 없는 사진은 현장 자동 분류가 되지 않을 수 있습니다.
